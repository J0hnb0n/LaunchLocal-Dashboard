## Form Upgrade Path

The contact form currently uses a `mailto:` action, which opens the user's email client. This is unreliable (not all browsers/devices support it). Before launch:

1. Create a free account at [formspree.io](https://formspree.io)
2. Create a new form pointing to the restaurant's email
3. In `index.html`, replace:
   ```html
   action="mailto:info@lamschinesefood.com" method="POST" enctype="text/plain"
   ```
   with:
   ```html
   action="https://formspree.io/f/YOUR_FORM_ID" method="POST"
   ```
4. In `script.js`, the form submit handler has a comment showing where to add `fetch`-based async submission for a better UX.

## Design Decisions

| Decision | Reason |
|---|---|
| Heading font: Lora (serif) | Conveys tradition and craft; appropriate for a family-run Chinese restaurant |
| Accent: `#C8960C` (warm gold) | Default yellow (`#f3ec1b`) is too harsh on light backgrounds; gold is more elegant and culturally resonant |
| Background alt: `#FDF8F3` (warm cream) | Warmer than grey; evokes warmth and hospitality |
| Red primary: `#af0404` | Standard brand default; works well for Chinese restaurant (culturally significant colour) |
