### Scroll Animation
- `#hero-scroll` = 480vh; inner `#hero-sticky` = sticky 100vh
- Canvas opacity driven by scroll progress (`prog * 18`) — invisible at position 0
- Canvas CSS transition: `0.6s ease`; wordmark fades in at ~88% scroll
- `--bg: #eae3d4` must match animation's linen backdrop exactly

### Page Structure
1. `#hero-scroll` — canvas animation
2. `#menu` — menu section
3. `#gallery` — "The Food" / "Fresh From The Shack"
4. `#pss` — People / Story / Setting tabbed section (tab JS: `data-panel` → `#pss-{panel}`)
5. `#visit` — hours, map
6. `footer`

### Menu System
- Default menu hardcoded in JS as `DEFAULT` object
- Admin modal via footer "Manage Menu" link — **password: `henhouse`**
- Persisted in Firebase Firestore: `menu/lb_menu_v2`
- Firebase project: `little-bones-grill` (Spark); config embedded in `index.html`
- `renderMenu()` async — fetches Firestore on load, seeds from `DEFAULT` if empty
- ⚠️ If online ordering is ever added: replace password-in-JS with Firebase Auth first
