# assets/

Drop images into this folder and update the CSS/HTML references accordingly.

## Required Images

### glasses-wall.jpg
The main feature photo — the wall of glasses frames from the store.
How to get it: Save the image directly from https://www.tayloroptical.ca/
Recommended size: 1600px wide minimum
Used in: The "Every Pair, Taylor-Made" section (section#glasses-wall)
CSS reference: background-image in .gw-photo

### hero-bg.jpg (optional)
A full-bleed hero background image (wide shot of the store interior, or an abstract optometry image).
The hero currently uses a CSS-only navy/lens design which looks great without a photo.
If you add one: uncomment the background-image line in #hero in style.css.
