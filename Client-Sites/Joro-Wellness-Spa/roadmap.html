1
CorePhase 1 · pre-transfer prep

Audit Drew's existing Squarespace

Before touching anything, get the lay of the land on Drew's current Squarespace site so the transfer has no surprises.

  • Get login / collaborator access to Drew's Squarespace account
  • Catalog what exists today — pages, forms, integrations, FlyBook embed, domain setup, payment processor
  • Confirm Squarespace plan tier supports what we need (custom code, email, forms)
  • Back up current site (export + screenshot key pages) before any edits
Deliverable: Short audit doc — what's there, what's missing, what gets replaced.
2
CorePhase 2 · the big move

Transfer the new design to Squarespace

Port the demo's design + content to Drew's Squarespace. Some sections rebuild as native Squarespace blocks, others go in as code injections.

  • Recreate the hero, experience cycle, and pricing sections using Squarespace blocks
  • Port the Wellness Journal articles into Squarespace's native blog
  • Wire up the private booking form (native Squarespace form → email)
  • Re-embed FlyBook booking widget in the right spots
  • Match fonts (Cormorant Garamond + Outfit) and colour palette in Squarespace site styles
  • Port nav, footer, social links
  • Check responsive layout on mobile / tablet
  • Domain + DNS — point joro's existing domain at the new site, set up redirects from old URLs
  • Verify Google Analytics / search console still pointing at the new site
Deliverable: New site live on Drew's Squarespace at the production domain.
3
CorePhase 3 · handoff

Drew training + launch checklist

Make sure Drew can self-serve the small stuff before we walk away from the core delivery.

  • Walk Drew through editing pages, adding journal posts, swapping images
  • Show him where private booking form submissions land
  • Confirm FlyBook bookings are flowing as expected post-transfer
  • Quick written cheat-sheet for the 5 things Drew is most likely to want to change
Deliverable: Drew confident running the site day-to-day. Core engagement complete.
4
UpsellPhase 4 · automated re-engagement emails

Automated reminder email setup

The 30/60/90-day re-engagement sequence Drew bought as an upsell. Designs are preserved in /Email-Reminders/email-previews.html.

  • Confirm with Drew which email platform he's using or wants (Mailchimp / Squarespace Email / Brevo)
  • Figure out FlyBook → email tool data path (last-visit date is the trigger we need)
  • Build the three email templates as table-based HTML for client compatibility
  • Set up automation rules: 30/60/90 days after last booking
  • Add unsubscribe handling, branded sender domain, test send to Drew + a few real addresses
  • Document the setup so Drew can pause / edit copy himself
Deliverable: Live automated email sequence. Past guests start receiving emails on the right schedule.
5
UpsellPhase 5 · KPI dashboard

KPI dashboard build

The 2025 measurables dashboard Drew bought as an upsell. Source data is in /Dashboard/KPIs - Dashboard - 2025.xlsx.

  • Confirm with Drew where the dashboard lives (private link? embedded in Squarespace? standalone hosted page?)
  • Decide refresh cadence (monthly manual update? automated?) and who owns updates
  • Finish chart polish + ensure the numbers match the Annual Dashboard sheet exactly
  • Add a way for Drew to see year-over-year comparisons once 2026 data starts flowing
  • Hand-off doc: how to update the data, what each chart means
Deliverable: Drew has a KPI view he can check anytime to see how the spa is trending.
6
OngoingPhase 6 · steady-state support

Ongoing support

Once everything is live, settle into a rhythm. Whatever cadence Drew and Johnathon agree to.

  • Define support scope — what's included, what's billable
  • Set check-in cadence (monthly review? quarterly?)
  • Track new ideas / future upsells (AI chatbot is parked — Drew passed for now, may revisit)
  • Monitor email deliverability + dashboard freshness
  • Periodic content suggestions for the Wellness Journal (SEO compounding effect)
Deliverable: Drew is happy, the site works, the upsells are paying off. Long-term relationship.
